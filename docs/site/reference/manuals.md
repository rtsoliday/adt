# Download the manuals

The operator guide is extracted from the same source as ADT's **Help Topics**
and **User Manual** actions.

- <a href="../downloads/adt-manual.html" target="_self">Standalone HTML manual</a>
- <a href="../downloads/adt-qt-guide.md" download>Operator guide in Markdown</a>
- <a href="../downloads/README.md" download>README build and behavior reference</a>

The HTML manual includes all twelve guide topics, a table of contents, and
styles for offline reading. In the application, **F1** opens the searchable
guide and **Help > User Manual** opens its HTML copy in a browser.
`ADT_HELP_PATH` selects a manual file or URL for that application action.
