# ADT (Qt) documentation

<!--@include: ./_includes/version.md-->

See the [release notes](./project/release-notes) for changes in this version.

Display EPICS process-variable arrays in machine order, compare live values
with stored sets or a reference, and inspect individual readings.

## Open a display

[Build ADT](./get-started/install), then choose a PV file from
**File > Load** or use **Custom...** for another file.
The [first-display guide](./get-started/first-display) explains the display
areas, statistics, unavailable readings, and point details.

## Work with arrays

- [Adjust the display](./operate/display-areas) with markers, lines, bars,
  scale controls, and maximum/minimum envelopes.
- [Zoom and pan](./operate/zoom-area) through the machine layout.
- [Check status](./operate/status) and identify excluded or unavailable readings.
- [Compare stored sets and references](./operate/stored-sets).
- [Save snapshots or plot data](./operate/snapshots-plots).

## Configure and look up

The [PV-file reference](./reference/pv-files) describes array definitions and
display parameters. [Configuration files](./reference/configuration) select
directories and Load menus. [Command-line options](./reference/command-line)
and the [keyboard and mouse reference](./reference/keyboard-shortcuts) cover
startup and navigation.

[Download the complete manual](./reference/manuals) for a single-page HTML
copy or the original Markdown.
